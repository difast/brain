Как начать

Первое устройство — за один день

1
Развёртывание

Компоненты

Из чего состоит платформа

Слоистая архитектура: логические сервисы внутри единого разворачиваемого бэкенда.
Реестр устройств
Robot Registry

Регистрация устройств, тип, доступные команды и статус подключения. Устройство описывается данными — новый тип не требует изменений ядра.

Движок задач
Task Engine

Постановка задач с приоритетом, очередь и выборка следующей задачи устройством. Сценарии от оператора и от самого устройства.

Движок решений
Decision Engine

Собирает промпт из возможностей устройства, вызывает языковую модель и возвращает строгий JSON. Ядро платформы.

Память и обучение
Memory Layer

История действий, задач и результатов исполнения. Недавняя обратная связь подмешивается в следующее решение.

Телеметрия
Telemetry

Заряд, скорость, координаты и ошибки в реальном времени. Присутствие устройства отслеживается в БД — без внешних кэшей.

Трансляция команд
Action Translator

Универсальные действия модели отображаются в конкретные команды устройства. Неподдерживаемое отсекается, а не выполняется наугад.

Симулятор
Simulator

Виртуальное устройство с живой телеметрией. Интеграция и сценарии проверяются до появления физического железа.

Интеграция
SDK / API

SDK для Python, JavaScript, Go, C++ и C плюс REST API. Устройство действует «как оно само» — идентификатор берётся из токена.
